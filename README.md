## ⌨️ Atajos de Teclado

> **SUPER = Tecla Windows**

<details>
<summary>🚀 Aplicaciones</summary>

| Atajo | Acción |
|--------|--------|
| `Super + Enter` | Abrir Kitty |
| `Super + D` | Abrir Rofi |
| `Super + B` | Abrir Firefox |
| `Super + Escape` | Recargar SXHKD |
| `Super + Shift + R` | Reiniciar BSPWM |

</details>

<details>
<summary>🪟 Gestión de Ventanas</summary>

| Atajo | Acción |
|--------|--------|
| `Super + X` | Cerrar ventana |
| `Super + M` | Alternar modo Monocle |
| `Super + T` | Modo Normal |
| `Super + Shift + T` | Modo Pseudo Normal |
| `Super + S` | Modo Floating |
| `Super + F` | Pantalla completa |

</details>

<details>
<summary>🎯 Navegación entre Ventanas</summary>

| Atajo | Acción |
|--------|--------|
| `Super + H` | Ir a la ventana izquierda |
| `Super + J` | Ir a la ventana inferior |
| `Super + K` | Ir a la ventana superior |
| `Super + L` | Ir a la ventana derecha |
| `Super + ←` | Ir a la ventana izquierda |
| `Super + ↓` | Ir a la ventana inferior |
| `Super + ↑` | Ir a la ventana superior |
| `Super + →` | Ir a la ventana derecha |

</details>

<details>
<summary>🔄 Mover Ventanas</summary>

| Atajo | Acción |
|--------|--------|
| `Super + Shift + H` | Mover ventana a la izquierda |
| `Super + Shift + J` | Mover ventana abajo |
| `Super + Shift + K` | Mover ventana arriba |
| `Super + Shift + L` | Mover ventana a la derecha |

</details>

<details>
<summary>📚 Espacios de Trabajo</summary>

| Atajo | Acción |
|--------|--------|
| `Super + 1-0` | Cambiar de workspace |
| `Super + Shift + 1-0` | Mover ventana al workspace |
| `Super + Ctrl + ←` | Workspace anterior |
| `Super + Ctrl + →` | Workspace siguiente |

</details>

<details>
<summary>🧭 Historial de Foco</summary>

| Atajo | Acción |
|--------|--------|
| `Super + Tab` | Última ventana utilizada |
| `Super + Grave` | Último nodo |
| `Super + C` | Ventana siguiente |
| `Super + Shift + C` | Ventana anterior |

</details>

<details>
<summary>📐 Preselección BSPWM</summary>

| Atajo | Acción |
|--------|--------|
| `Super + Ctrl + H/J/K/L` | Elegir dirección de división |
| `Super + Ctrl + 1-9` | Elegir proporción |
| `Super + Ctrl + Space` | Cancelar preselección |
| `Super + Ctrl + Shift + Space` | Cancelar todas las preselecciones |

</details>

<details>
<summary>📏 Redimensionar Ventanas</summary>

| Atajo | Acción |
|--------|--------|
| `Super + Alt + ←` | Redimensionar izquierda |
| `Super + Alt + ↓` | Redimensionar abajo |
| `Super + Alt + ↑` | Redimensionar arriba |
| `Super + Alt + →` | Redimensionar derecha |

</details>

<details>
<summary>🏷️ Estados Especiales de Ventana</summary>

| Atajo | Acción |
|--------|--------|
| `Super + Ctrl + M` | Marcar ventana |
| `Super + Ctrl + X` | Bloquear ventana |
| `Super + Ctrl + Y` | Sticky (visible en todos los workspaces) |
| `Super + Ctrl + Z` | Privada |


</details>
